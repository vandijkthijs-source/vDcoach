01 / ANDROID

Verbind je telefoon

Open Tailscale op beide apparaten. Ga in de bijgewerkte app naar Instellingen → Serververbinding.

Het verbindingstoken staat lokaal in server/data/token. Het wordt hier niet getoond. Een nieuwe Android-build is nodig voor automatische synchronisatie.
